---
name: Readable UI text
description: Project-wide text-size, contrast, and plain-language expectations.
---

Keep visible text comfortably readable on every screen. Avoid tiny labels and pale secondary text; use a 12px minimum for utility text, stronger contrast, and plain-language copy.

**Why:** the user asked that all page text be clearly visible, readable, and friendly.

**How to apply:** Use the shared readability rules across app, access, customer, and dialog screens. Preserve heading hierarchy, and check narrow layouts for wrapping after typography changes.
